# Agent Instructions

This project uses `.agents/` as its agent memory and handoff folder.

IMPORTANT: Do not edit this AGENTS.md file for project memory, state, tasks, decisions, or handoff notes. This file is only a pointer. Put all project memory updates in `.agents/`.

Before making changes:
1. Read `.agents/README.md`.
2. Read every file in `.agents/`.
3. Treat `.agents/state.md`, `.agents/tasks.md`, and `.agents/last-session.md` as the primary session state.
4. Keep the relevant files in `.agents/` updated before ending the session.

Do not skip the `.agents/` files. Do not write session state into AGENTS.md. The `.agents/` folder is the source of truth for agent context in this project.
